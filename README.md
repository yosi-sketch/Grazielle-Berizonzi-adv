# Gabriela Santana — Advocacia Previdenciária

Site institucional da advogada Gabriela Santana, com atuação previdenciária em Itajubá, Minas Gerais.

## Desenvolvimento

- Instale as dependências com npm install.
- Inicie o ambiente local com npm run dev.

O site usa Next.js App Router, Tailwind CSS 4 e Framer Motion. Os arquivos da marca e o retrato usado na página ficam na pasta public.
