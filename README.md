# Grazielle Berizonzi Advocacia

Site institucional de Grazielle Berizonzi, advogada em Muriaé, Minas Gerais.
Apresenta sua atuação jurídica, informações do escritório e canais de contato.

## Desenvolvimento

- Instale as dependências com npm install.
- Inicie o ambiente local com npm run dev.

O site usa Next.js App Router, Tailwind CSS 4 e Framer Motion. O logo e os
retratos locais ficam na pasta public; favicon e imagem para compartilhamento
são gerados pelo App Router.
